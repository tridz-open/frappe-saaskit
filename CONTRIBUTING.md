# Contributing

This site is early alpha documentation and is not currently accepting pull requests or outside contributions. Pull requests will be closed without review.

**Issues are welcome.** If you find a mistake or a problem, please [open a GitHub issue](https://github.com/tridz-open/frappe-saaskit/issues/new/choose).

Do not file security problems as public issues. See [SECURITY.md](SECURITY.md).

## Use at your own risk

Alpha software and documentation, provided "as is" without warranty of any kind (see [LICENSE](LICENSE)).

## Local build (for your own fork)

```bash
(Node 22)
npm ci && NEXT_PUBLIC_BASE_PATH=/frappe-saaskit npm run build
```
