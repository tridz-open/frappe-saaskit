# frappe-saaskit

Documentation source for the **Frappe SaaS**, published at <https://frappesaas.tridz.in/>.

The kit is three alpha repos: [saas_core](https://github.com/tridz-open/saas_core), [fcctl](https://github.com/tridz-open/fcctl) and [frappe-saaskit-starter](https://github.com/tridz-open/frappe-saaskit-starter). Agents: see [llms.txt](https://frappesaas.tridz.in/llms.txt); every page is also available as raw Markdown at its URL with `.md` appended (without the trailing slash).


Build: `npm ci && NEXT_PUBLIC_BASE_PATH=/frappe-saaskit npm run build` (static export to `out/`). Unset the env var when serving from a custom domain root.
