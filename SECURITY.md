# Security policy

This repository holds documentation only. It is early alpha material, provided "as is" without warranty of any kind (see [LICENSE](LICENSE)).

## Reporting a vulnerability

Report security issues **privately**, not in public issues. Use GitHub's private vulnerability reporting: open the repository's **Security** tab and click **Report a vulnerability** (<https://github.com/tridz-open/frappe-saaskit/security/advisories/new>).

Security problems in the software itself belong on the relevant repo: [saas_core](https://github.com/tridz-open/saas_core/security/advisories/new), [fcctl](https://github.com/tridz-open/fcctl/security/advisories/new), [frappe-saaskit-starter](https://github.com/tridz-open/frappe-saaskit-starter/security/advisories/new). We aim to acknowledge within 7 days.
