# Getting started

Pick the path that matches what you want today.

<Shot name="pricing" alt="Starter pricing page, the first thing you see in fixture mode" caption="Fixture mode shows pages like this with no backend." />

| I want to... | Do this | Needs |
|---|---|---|
| Just look at the customer UI | Run the starter in fixture mode: `git clone` [frappe-saaskit-starter](https://github.com/tridz-open/frappe-saaskit-starter), then `npm ci && npm run dev` | Node 20.19+ or 22.12+ |
| See the whole flow locally, no Frappe Cloud | Follow the [Local demo](/guides/local-demo/) (fake `fcctl`) | Frappe v16 bench, MariaDB, Redis, Node, Python 3.11+ |
| Put my own app behind it | [Writing a recipe](/guides/writing-a-recipe/), then the demo with your template | The above |
| Take real payments (test mode) | [Payments](/guides/payments/) | Razorpay test account |
| Provision real sites | `saas_core` [DEPLOY.md](https://github.com/tridz-open/saas_core/blob/main/DEPLOY.md) and the [fcctl README](https://github.com/tridz-open/fcctl#readme) | A Frappe Cloud v2 team |
| Use `fcctl` alone | The [fcctl README](https://github.com/tridz-open/fcctl#readme) | A Frappe Cloud v2 account |

Always check [Versions](/status/versions/) first and pin the tags listed there.
