## Prerequisites

| Path | Needs |
|---|---|
| Starter, fixture mode | Node 20.19+ or 22.12+ |
| Local demo, your own recipe | Frappe v16 bench, MariaDB, Redis, Node, Python 3.11+ |
| Real provisioning, fcctl alone | A Frappe Cloud v2 team with the `server:console` capability, Python 3.11+ |
| Test payments | A Razorpay test account |

## 60-second look

<Steps>

### Clone the starter

```bash
git clone https://github.com/tridz-open/frappe-saaskit-starter.git && cd frappe-saaskit-starter
```

### Run it

```bash
npm install && npm run dev
```

### Open it

Go to `http://localhost:5173`, then try a scenario such as `?scenario=past_due`.

</Steps>

<Screenshot name="pricing" alt="Starter pricing page, the first thing you see in fixture mode" caption="Fixture mode shows pages like this with no backend." frame="browser" />

| URL | Shows |
|---|---|
| `/?scenario=default` | Normal account with two instances |
| `/signup?scenario=invite_only` | Signup that requires an invitation |
| `/console?scenario=empty` | New account with no instances |
| `/console/billing?scenario=past_due` | Past-due subscription banner |
| `/console?scenario=provision_failed` | Provisioning that fails |
