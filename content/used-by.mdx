# Used by

Products and companies using Frappe SaaS.

## URY

[URY](https://ury.app) is an open-source restaurant POS and ERP built on Frappe. It runs its signup, billing and Frappe Cloud provisioning on the kit.

## Huf

[Huf](https://huf.ai) is an open-source multi-agent AI framework built on Frappe.

## Franchise Media
