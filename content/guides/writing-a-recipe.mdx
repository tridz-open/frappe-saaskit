# Writing a recipe

<p className="lede">A recipe is the extension point that turns your Frappe app into something saas_core can provision for each customer. It has two parts.</p>

## 1. The Template

The Template (data) says what a new tenant site is: apps, golden backup, hooks, health checks. Full field reference: [Templates and recipes](/concepts/recipes/) and [TEMPLATES.md](https://github.com/tridz-open/saas_core/blob/main/docs/TEMPLATES.md).

- `backup_source`: a Frappe Cloud site backup or a sha256-verified bucket backup; empty means a fresh site.
- `hooks`: ordered `{name, version, args}`. End every template with `core.scheduler_resume` and `core.maintenance_off`, or the site stays at 503.
- `is_public`: must be ticked for any template a public Plan uses.
- `site_admin`: tick it if your hooks need administrator access.
- `health_checks`: `{name, path, expect}` requested over HTTPS after provisioning.

### Minimal working example

```json
{
  "slug": "starter",
  "title": "Starter",
  "is_public": 1,
  "site_admin": 1,
  "apps": [{"app": "frappe", "install_order": 1}, {"app": "erpnext", "install_order": 2}],
  "backup_source": {"bucket": "acme-backups", "prefix": "golden/starter/20260101_000000", "manifest": "golden/starter/manifest.json"},
  "hooks": [
    {"name": "acme.seed", "version": "1", "args": {}},
    {"name": "core.scheduler_resume", "version": "1"},
    {"name": "core.maintenance_off", "version": "1"}
  ],
  "health_checks": [{"name": "login", "path": "/login", "expect": 200}],
  "site_config": {}
}
```

## 2. The Recipe class

Code, optional. Registered through the entry-point group `saas_core.recipes`. It has `slug`, `template_defaults()`, `hooks()` returning a dict of `name@version` to callable, `tenant_config(tenant, plan, fields)` and `signup_schema()`. Name the Template's `recipe` field after the recipe `slug`. Lookup is `saas_core.recipes.registry.get(slug)`.

> [!WARNING]
> There is no skeleton upstream. The sketch below is built only from the contract names and is **untested**. Installing a recipe package into the bench environment is untested too.

## 3. Test it

Run with the fake fcctl (`saas_core_fake_fcctl=1`, see the [Local demo](/guides/local-demo/)) and provision a throwaway tenant from your template before pointing it at Frappe Cloud.
